# MMM-BBI-bibliometrics----code
This repository contains the supplementary materials for the paper "Mapping data-science applications in ecosystem service research: A CICES-based bibliometric and decision-oriented synthesis". It includes the complete datasets and analysis code used in the study for reference and reproducibility.
Repository Structure
all/ — Complete raw dataset downloaded from Web of Science (WoS)
annotated_wos_data/ — Classified literature dataset covering three categories of ecosystem services
code/ — Main analysis scripts for bibliometric computation and classification
50m_cultural/ — Geospatial data (50 m resolution) for cultural ecosystem service mapping
100m_cultural/ — Geospatial data (100 m resolution) for cultural ecosystem service mapping

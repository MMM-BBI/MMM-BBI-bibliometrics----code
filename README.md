# Supplementary Materials: Mapping Data-Science Applications in Ecosystem Service Research

This repository contains the supplementary materials for the paper **"Mapping data-science applications in ecosystem service research: A CICES-based bibliometric and decision-oriented synthesis"**.

It includes the complete datasets and analysis code used in the study, for reference and reproducibility.

## Repository Structure

- `annotated_wos_data/` — Classified literature dataset covering three categories of ecosystem services
- `code/` — Main analysis scripts for bibliometric computation and classification

---

For questions or further information, please refer to the original publication.
